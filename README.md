# Fatih Maulana - Personal Portfolio

A high-performance, interactive personal portfolio built with Next.js 14+, featuring a physics-based hero section using Matter.js.

## 🚀 Features

- **Physics Hero Section** - Interactive drag-and-throw skill tags powered by Matter.js
- **Gravity Toggle** - Switch between physics mode and static layout
- **MDX Blog** - 10 technical articles with full content
- **Bento Grid Layout** - Showcase projects with varied card sizes
- **SEO Optimized** - JSON-LD schemas, sitemap, Open Graph
- **Mobile Responsive** - Physics disabled on mobile for better UX
- **Accessibility** - Focus states, semantic HTML, ARIA labels

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Animation**: Framer Motion
- **Physics**: Matter.js
- **Blog**: MDX with next-mdx-remote
- **Analytics**: Vercel Analytics

## 📁 Project Structure

```
src/
├── app/                 # Next.js App Router pages
│   ├── blog/           # Blog routes
│   ├── sitemap.ts      # Dynamic sitemap
│   └── robots.ts       # Crawler config
├── components/
│   ├── hero/           # Physics-enabled hero components
│   ├── layout/         # Navigation, Footer, Section
│   ├── sections/       # About, Work, Contact
│   └── ui/             # Button, Card, Tag
├── content/
│   └── blog/           # MDX blog posts
├── hooks/              # Custom React hooks
└── lib/                # Utilities, data, metadata
```

## 🏃 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
